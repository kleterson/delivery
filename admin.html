Como o seu painel (admin.html) já tem os campos de Endereço de Entrega e Distância em KM, basta adicionar um código em JavaScript que, assim que você terminar de digitar o endereço (ou clicar fora do campo), busca as coordenadas e calcula a rota de moto/carro a partir do endereço fixo do seu comércio. image_fe0f64.png Existem duas formas principais de fazer isso: 1. Opção 100% Gratuita (Nominatim + OSRM) Não precisa de cartão de crédito nem chave de API paga. Funciona usando o banco de dados do OpenStreetMap: Nominatim API: Converte o endereço digitado (ex: "Rua das Flores, 50, São Vicente") em latitude e longitude. OSRM API (Open Source Routing Machine): Traça a rota real pelas ruas entre o ponto fixo do comércio e o destino, retornando a distância exata em metros (que o script divide por 1000 para jogar no campo Distância em KM). image_fe0f64.png Ponto de atenção: Para não errar a cidade, o ideal é o script já concatenar o nome da cidade e estado automaticamente no final da busca (ex: + ", São Vicente - SP"). 2. Opção Profissional (Google Maps Distance Matrix / Places API) Vantagem: Tem autocompletar de endereço enquanto você digita (igual app de delivery) e encontra números de casas com muito mais precisão. Custo: O Google dá US$ 200 de crédito gratuito todo mês (o que cobre milhares de cálculos de rota por mês sem custo real), mas exige cadastrar um cartão de crédito no Google Cloud para ativar a chave.
